## The session's reading

`ABILITY_POOL` in `src/data/abilities.ts` is generated by
`scripts/gen-pools.ts`, which already drops abilities that are blanks in this
game (`SPECIES_LOCKED_ABILITIES`, including "no-op in a singles game"). Ball
Fetch, Honey Gather and Run Away have no handler at all in `@pkmn/sim`, and a
further group only ever touches a doubles ally, which a `gen9customgame`
singles battle never has. Both are the same shape as the existing exclusions,
so the fix belongs in the generator's rule, not in `data/blacklists.ts`, whose
bar is "mechanical or measured" for things that *do* something.
