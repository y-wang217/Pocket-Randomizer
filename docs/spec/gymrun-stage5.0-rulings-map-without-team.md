## The prompt, verbatim

> the map doesn't need to have the team on it you can conserve space

## What it rules

| Item | Ruling |
|---|---|
| The map's party HUD | **Removed from the map screen.** The team is one tap away on the Team tab, which from the map opens the writable party screen (reorder, lead, items), the same screen the Manage button opened; on desktop the sidebar shows the team beside the frame. |
| The Manage button | Goes with the HUD. The Team tab is the route, and it disarms the teach boundary as Manage did. |
| The wallet | **Stays on the map**, as the currency mark and a number in the heading: a shop's price on the next step is only a decision if the coins are on screen, and the wallet is not a team fact. |
| The space | Goes to the graph. |

Stage 4's argument for the HUD (*"a rest node is only a real option if the
cost of skipping it is visible at the moment you skip it"*) is superseded by
this ruling, and recorded as such in `../generation.md` rather than deleted.
