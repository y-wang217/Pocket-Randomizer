## Four things Tier 5 should know

**1. The census fixture has been measuring a screen the app does not render.**
M4.3 fixed the battle node — `A loaded board` and `A trainer` were harness
naming, five words charged to that surface since M0.1 — and found something
worse beside it: `ui/gallery.ts` attached the battle screen with **no segment**,
and the AI tier line is built only when there is one, so `Rookie`, `Seasoned`
and `Ace` have rendered on every real battle screen since the tiers patch and
been counted on none.

**Check the fixture before trusting a number on any surface you are about to
work on.** The correction that *raised* the count is the one that mattered.

**2. A fixture that cannot produce the condition an item exists for cannot
measure that item.** M4.1 and M4.2 both moved the census by zero, honestly: the
loaded board's turn has one status per side and is decided by Speed, so it never
produces a flag collision for a precedence rule to cut or a bracket for a
chevron to mark. Both were asserted directly instead. §61 and §62 say so rather
than claiming a reduction.

**3. The mapper returns everything and the strip cuts.** `ui/abnormality.ts`
reads the same flag list for its animation beats and used to say *"the strip
carries the rest"*. If you ever move a filter upstream of `ui/flag-strip.ts` you
will silently change which animations play, and no done-when in this list would
catch it.

**4. R7's exposure label does not exist yet.** D26's ruling says the label
carries the pull gesture's first encounter; M1.3 built the store and counts, and
nothing renders a label until **M6.1**. The handle is visible and the tap is
unchanged, so nothing is unreachable — but the pull is undiscovered. It is
recorded as an input to **M6.2**, which re-anchors the coach marks, because
section 7 gives coach marks and exposure labels one job each and a gesture
affordance is the former's.

## One document nearly went missing, and it is worth knowing how

[`4.10-tier-2.md`](4.10-tier-2.md) is in this directory because **Tier 4 put it
there**, not because Tier 2 did. It was written on
`claude/4-10-tier-2-plan-299kqy` in commit `947e89a`, *after*
[#63](https://github.com/y-wang217/Pocket-Randomizer/pull/63) had already
merged — so the handoff for a closed tier sat on a branch nobody would open
again, and `main` never had it. It surfaced only because a link to it from
`docs/README.md` failed `test/boundaries.test.ts`'s path check.

**A handoff written after its own pull request merges does not ship.** Write it
before the merge, or open a second one for it.

## Conventions this tier did not invent but did lean on

- **Delete the mechanism, not the fact.** M4.1 removed STAB and contact and the
  deletion reached two dex lookups, a species map, a type-change branch, a
  retraction pass and `createFlagReader` itself — a stateful reader whose only
  state was STAB's. A reader holding no state is a claim that stopped being
  true, so it went rather than becoming a wrapper.
- **Restate a rule that was written narrower than it was meant; never weaken
  it.** D27's three "no per-kind hue" sites became "no weight axis", which is
  what they always meant, and the test asserts the stronger thing.
- **Refuse a floor when it costs more than it buys, and say why.** The log
  handle is 24px tall, not 44: V5 budgets that strip at one band, `.flags` has
  `overflow: hidden` so an oversized hit area is clipped, and the first cut took
  the floor and failed `test/visual-v5.test.ts`. The width grew instead.
- **The gate catches doc rot too.** `test/boundaries.test.ts` resolves every
  backticked path in the live docs; §63 shipped two spelled `screens/battle.ts`
  and failed two legs on it. Fixed and the whole gate re-run rather than
  reasoned about.
