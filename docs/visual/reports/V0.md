# V0 report: tokens and type

Stage V0 of `docs/spec/gymrun-visual-identity-plan.md`, run unattended under
`docs/visual/OVERNIGHT.md`. Every checkpoint green; guarded screens equal the
baseline to the pixel; smoke passes.

## Morning decisions

1. **`--font-body`.** Numbers and prose render in the system monospace stack
   (the overnight's conservative default). Pixelify Sans is on headings, labels
   and chips only. If `docs/visual/reports/v0-legibility/*@2x.png` read fine on
   a real 390 phone, set `--font-body: var(--font-display)` in
   `src/ui/theme/tokens.css`. One line. Re-measure the guarded screens after:
   the display face is wider, and a wrap on the map blurb would move the
   decision point.
2. **`--accent` is hot pink `#ff2d95`.** The overnight rule (first of hot pink,
   acid lime, orange, cyan with over 30° of hue from every type token) has no
   winner: the nearest type hues are fairy 0°, bug 6°, fire 6°, ice 9°. The
   plan's own flagged default is hot pink, on the argument that the chips are
   desaturated outlines, so it stands. Cyan has the widest margin if you
   disagree. One line.
3. **Two off-scale tokens, `--fs-gate` (0.78rem) and `--space-gate` (0.35rem).**
   4.6c wrote the capability gate line in rem. Snapping it to the 12px step and
   the 6px half step moved the SMOKE24 map by −1.5px, and the height gate is
   absolute, so the two values are pinned as named tokens. Snapping them is a
   design call that needs a new `heights.json`.
4. **Fourteen `calc()` spacings.** The scale is 4px with 2px half steps; the
   stylesheet had 5px, 7px and 11px paddings and gaps on the guarded screens
   (move button gap, chip padding, node padding). They are written as
   `calc(var(--space-1) + var(--hairline))` and so on rather than snapped, for
   the same reason. Snapping them moves both guarded screens.
5. **`index.html`'s favicon still carries the old orange.** It is outside
   `src/ui/` and outside the inventory's scope. Swap the two hex values in the
   data URI if you want the tab to match.
6. **HP bars stay solid.** The plan's "only solid saturated fill" rule is
   about chrome; the HP bar is a readout, and a desaturated HP bar would be a
   worse instrument. Win and loss titles and the stage up/down colours on stat
   values stay for the same reason. Say so if you want them muted.

## V0.2 tokens and the face

`src/ui/theme/tokens.css`. Four base values (`--base-deep`, `--base-surface`,
`--cream`, `--cream-dim`); every other surface, border and text tone is a
`color-mix` of those four. Eighteen type tokens plus Stellar, moved from
`styles.css` (they were never in `data/`). Readout colours (HP bands, win and
loss, six statuses, stage up and down) kept. A 13-step type scale in the pixel
values the layout was built on. Spacing on a 4px scale with 2px half steps,
a `--hairline`, and the two pinned rem values above. Two radii, 4px for cards
and 2px for chips. `--motion-duration: 0ms`, because `data/tuning.ts` carries
no duration yet.

Pixelify Sans, SIL OFL 1.1, latin subset from the fontsource packaging of the
Google Fonts build, two weights:

## V0.3 apply

- `styles.css` reads tokens for every value; `test/visual-tokens.test.ts` scans
  every declaration and fails on a literal colour, face, size, radius or
  spacing, and on any use of `--accent` outside `.primary-action`.
- `.primary-action` replaces `.button--primary` in the seven screens that
  had one. The seed bar's Start run is a plain button, so the summary screen
  (where the seed bar is visible again) shows one accent, the rematch.
- Every accent job that was not the primary action reads `--emphasis` (the
  text cream): the title, focus rings, hover borders, the current step marker,
  the current rail gym, the lead's edge, the speed marker, the log's turn
  headers and first-actor ordinals, the tip's advice rule, the forced-switch
  heading.
- One chip recipe, keyed by `--chip`: faint fill, desaturated inset outline,
  hue in the text. Type chips, status chips, category and effectiveness
  badges, the lead badge, the priority tag. No chip is a solid fill and none
  is more saturated than another. `0x` keeps the loss hue at the same weight
  and size as the others.
- Tiers lose their amber and red; the four bands lose their opacity ramp;
  nodes lose their per-kind and per-tier edges; reward cards lose their
  per-kind edges; the coin readouts and the wallet lose the Electric yellow.
  All are attributes printed as text now.
- Headings and labels take the display face, upper case, letterspaced. Names
  (species, moves, items) and numbers keep the body face and their case.

## Deviations from the plan, recorded

- The plan's V0 asked for one face for everything with the two-face system as
  the phone fallback; the overnight prompt made the two-face system the
  default. Decision 1 is the swap back.
- The plan's spacing scale is 4px; the built scale has 2px half steps and
  fourteen `calc()` off-scale values (decision 4), because the vertical budget
  is a gate and the scale is not.
